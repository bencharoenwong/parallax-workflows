# Hong Kong vocabulary

Use Traditional script and Hong Kong finance terminology for `zh-HK`.
This is a scoped vocabulary overlay on the shared Traditional runtime data.
It is not a fully native-reviewed Hong Kong report corpus.

| Identifier | Preferred gloss | Also accepted |
|---|---|---|
| P/E | 市盈率 | |
| P/B | 市賬率 | 市淨率 |
| ROE | 股東權益回報率 | 股本回報率 when the source clearly means total equity |
| EPS | 每股盈利 | |
| Dividend yield | 股息率 | 股息收益率 |
| Bull / Base / Bear case | 樂觀情景 / 基準情景 / 悲觀情景 | |

Keep P/FCF distinct from price/operating cash flow: use 股價自由現金流比 when a gloss is needed.
Taiwan's 本益比, 股價淨值比, 每股盈餘 and 股息殖利率 must not be imposed on Hong Kong output.

Sources: [HKEX equity FAQ](https://www.hkex.com.hk/global/exchange/faq/products/securities/equity-securites?sc_lang=zh-hk),
[HKEX financial metrics](https://www.hkex.com.hk/Listing/Sustainability/Shareholder-Value-in-Focus/Dividend-Yield-Ratio?sc_lang=zh-HK&tab=DYR&view=market),
