# Vietnamese meaning checks

| Confusion | Required distinction |
|---|---|
| ROE denominator as vốn điều lệ | ROE uses vốn chủ sở hữu |
| P/FCF described as operating cash flow | Preserve dòng tiền tự do |
| ECL replaced by Expected Shortfall | Preserve IFRS 9 credit loss vs portfolio tail-risk metric |
| Operating leverage as economies of scale | Keep English identifier until the gloss is reviewed |
| Overweight translated as tăng tỷ trọng | Preserve an existing relative position vs an action |
| Source USD replaced by VND | Preserve each source currency |
| English separators left in prose (`1,234.5`, `15.2%`) | Prose: `1.234,5`, `15,2%`; tables keep source form |
| `trillion` rendered as `tỷ`, or a rescaled amount | trillion = nghìn tỷ; keep the source number (`1,86 nghìn tỷ`) |
| `phòng ngoại` / `phòng tín dụng` | `room ngoại` / `room tín dụng` (fixed loanword) |
| KHẢ QUAN used for a Parallax rating | Dual-label Parallax rating; KHẢ QUAN is a broker-only tier |
| `EBT` / `NPAT` in prose | `LNTT` / `LNST` |
| "MSCI upgraded Vietnam" | FTSE Russell upgraded Vietnam; MSCI has not |
| Missing source hedge | Preserve có thể / dự kiến / nhiều khả năng when warranted |

These are concept checks and sourced conventions (`sources.md`), not an observed native-corrected model-error corpus.
