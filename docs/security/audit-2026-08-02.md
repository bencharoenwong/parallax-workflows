`AUDIT_COMMIT` is `dc727a5` ("evals: RunRecord metric extractor + derived
Parallax token model"), but **the working tree at audit time carries
substantial uncommitted changes on top of it** — this audit evaluates the
full repository as it stands on disk (committed history + working-tree

- `CHANGELOG.md`, `evals/graders/runrecord.py`, `evals/graders/token_model.py`

  scenario-analysis}/` (SKILL.md + one reference file each)
- `plugin/skills/...` mirrors of the above — the regenerated distribution
  bundle produced by `skills/_parallax/scripts/build_bundle.py`

**Substance of the delta:** documentation of two previously-"unverified"
Parallax MCP endpoint token costs (now measured and priced at 1 token each),
propagated through the dependent workflow cost estimates in four skills plus
the shared conventions/coverage docs, and a matching simplification of the
eval-harness token model (`evals/graders/token_model.py`,
`evals/graders/runrecord.py`) that removes the now-unused "unverified token"
accumulator (`UNVERIFIED` set, `tokens_unverified` field,
`parallax_tokens_unverified` on `RunRecord`). No code path with a security
surface (network I/O, auth, request parsing, HTML/DOM rendering, shell
execution) is touched by this delta — it is Markdown pricing prose plus a
pure-Python dataclass/dict simplification in an offline eval grader.

**Distribution-artifact focus (per request):** `plugin/` is the generated
bundle that ships to end users via the Claude Code plugin marketplace. Its
tracked contents were verified to match a fresh rebuild from `skills/`
(`test_tracked_plugin_bundle_matches_source`, part of the 53-test
`test_build_bundle.py` suite — full pass, see SEC-12) and were separately
canary-scanned in isolation (see SEC-12) — clean.
