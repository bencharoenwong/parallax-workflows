and its linked publication review. They remain historical evidence with their
stated scopes and limitations. The validation run at the commit above reviewed

and nothing was published.

Additional CLI reproductions established four guard gaps. This follow-up
reviews their changes, tests and matching contributor guidance:

- Ordinary backslash separators now receive the same name matching as other
  supported separators, including in paths.
- Archive member paths receive the same private-artifact path checks as files.
- Explicitly incompatible registry prefix widths are rejected. An absent width
  keeps the existing version-two default; no registry migration is introduced.
- A proposed revision without a trusted baseline fails before scanning.
