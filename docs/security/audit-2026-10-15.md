## Security-relevant change

**`skills/_parallax/run_trace.py` (new) + five wired helper call sites
(`render_gate.py`, `coverage_check.py`, `client-policy/adaptation.py`,
`client-policy/reconcile.py`, `house-view/audit_append.py`).** When the
environment variable `PARALLAX_E2E_TRACE` names the live-journey runner's
trace file, each traced helper appends one JSON line recording the helper
name, the resolved script path, the exit code, and per input the role,
source (file/stdin/inline), file base name, and a sha256+size digest; the
render gate additionally records its skill key and an output digest. Read
`skills/_parallax/run_trace.py` directly and confirmed:

- **No file creation.** `finish()` opens with `os.open(path, flags)` where
  `flags` never includes `O_CREAT` (`run_trace.py:88`, comment: "no O_CREAT:
  the runner made the file"). The runner (`evals/concierge_journeys.sh:201-203`)
  pre-creates and `chmod 600`s the file before each run.
- **`O_NOFOLLOW`** is in the open flags (`getattr(os, "O_NOFOLLOW", 0)`,
  `:86-87`).
- **Post-open checks on the same descriptor, before any write:** regular
  file (`stat.S_ISREG`), `st_nlink == 1`, mode exactly `0o600`, and
  `st_uid == os.getuid()` — all four ANDed in one `if` (`:91-93`) that gates
  the `os.write` call. A symlink swapped in after a TOCTOU window, a
  hardlinked file, a non-owner file, or a loosened mode all fail closed to
  "write nothing."
- **Basename pinned.** `finish()` returns immediately unless
  `os.path.basename(path) == TRACE_NAME` (`"journey-trace.jsonl"`, `:83`) —
  an env var pointed at an arbitrary file name is refused before `open()`.
- **`O_NONBLOCK`** is in the open flags (`:87`), so a FIFO swapped in for the
  trace path cannot hang the helper.
- **All exceptions swallowed.** The entire body of `finish()` is wrapped in
  `try/except Exception: pass` (`:81`, `:97-98`); a trace failure cannot
  raise into the caller.
- **No payload text.** `_entry()` (`:66-76`) and `_digest()` (`:40-41`) emit
  only `role`, `source`, `name` (basename), `sha256`, and `size` per input,
  plus the same shape for `output`; the skill key is validated against
  `^[a-z0-9-]{1,64}$` (`:32`, `:63`) before being stored. No file content,
  no full path beyond the realpath of the script itself, is ever written to
  the trace line.
- **Exit code and stdout unchanged.** `run(helper, script, main)` (`:107-118`)
  calls `main()`, catches and re-raises `SystemExit` unchanged, and calls
  `finish()` in a `finally` block that cannot affect the return value; it
  never touches stdout. Each of the five call sites replaces
  `sys.exit(main())` with `sys.exit(_trace.run(...) if _trace else main())`
  — the untraced path (`_trace is None`, i.e. the env var unset) is
  byte-for-byte the pre-existing `main()` call.
- **Loaded by path only when the variable is set.** Each helper's
  `_run_trace()` checks `os.environ.get("PARALLAX_E2E_TRACE")` first and
  returns `None` immediately if unset, before any `importlib` call; only
  when set does it `importlib.util.spec_from_file_location("_parallax_run_trace",
  .../run_trace.py)` and cache the module in `sys.modules` so a process
  loads it once. An ordinary (untraced) run imports nothing new. Verified by
  direct read of all five call sites (`render_gate.py`, `coverage_check.py`,
  `client-policy/adaptation.py`, `client-policy/reconcile.py`,
  `house-view/audit_append.py`) — identical pattern in each.
- **Positive test coverage for exactly these invariants.**
  `skills/_parallax/test_run_trace_helpers.py::test_unset_variable_writes_nothing_and_loads_nothing`
  (parametrized over all five scripts) asserts
  `'_parallax_run_trace' not in sys.modules` and the trace file stays empty
  when the variable is unset; `::test_unset_variable_leaves_output_and_exit_code_unchanged`
  asserts a traced and an untraced `render_gate.py` run produce identical
  `(returncode, stdout, stderr)`. Both ran green this pass (see Verification).
- **`build_bundle.py` wiring.** `run_trace.py` is added to `PARALLAX_INCLUDE`
  and to `RUNTIME_COMPANIONS` for all five callers
  (`skills/_parallax/scripts/build_bundle.py`); `diff plugin/skills/_parallax/run_trace.py
  skills/_parallax/run_trace.py` — identical.

**Eval-only runner pieces (`evals/concierge_journeys.sh`,
`evals/make_python_shims.py`, `evals/scratch_snapshot.py`).** Test
infrastructure (owner-run, not CI, not shipped in `plugin/`), reviewed for
the two items the task flagged:

- **Shell quoting in generated Python-start shims.** `make_python_shims.py`'s
  `shim_text()` builds each shim with `shlex.quote()` on every interpolated
  value (`logger_python`, the fixed `LOGGER` source string, `name`, `log`)
  and passes the caller's real argv through only as `"$@"` (`:46-52`) —
  standard, correctly-quoted bash array expansion, not string-built. No
  value from an untrusted source reaches the shim text unquoted.
- **The shim's own log open.** The embedded `LOGGER` script opens the log
  with `os.O_WRONLY | os.O_APPEND | getattr(os, "O_NOFOLLOW", 0)` and no
  `O_CREAT` (`:38`), matching `run_trace.py`'s discipline; the runner
  pre-creates and `chmod 600`s `python-starts.jsonl` the same way it does
  the trace file (`concierge_journeys.sh:202-203`). A logging failure cannot
  stop the real interpreter (module docstring, `:17`; the `try/finally`
  wraps only the `os.write`, and `exec` to the real interpreter happens in a
  separate shell line regardless).
- **`scratch_snapshot.py`** hashes files via `os.open(..., O_RDONLY |
  O_NOFOLLOW | O_NONBLOCK)` (`:24`) and lists (never follows) symlinks
  (`followlinks=False`, `:33`; `os.lstat`, `:37`) — consistent discipline,
  though this script runs read-only against the runner's own scratch tree
  after the model run ends, not a live trust boundary.
